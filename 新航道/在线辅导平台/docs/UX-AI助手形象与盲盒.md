# AI助手形象与盲盒系统 - UX交互文档

## 文档信息

- **产品**: 新航道学习机 - AI助手形象系统
- **更新日期**: 2026-05-07
- **关联页面**: 学习机首页、AI答疑首页
- **来源**: 学习机首页.png、机机基础形象.png、宇航员.png、运动员.png

## 1. 需求概述

在学习机首页AI助手区域增加AI助手形象展示功能，支持：
1. 在首页展示AI助手当前穿戴的形象
2. 查看形象收藏（弹框展示全部收藏）
3. 抽取盲盒获取新AI形象

---

### 3.4 形象卡片

**已拥有形象：**
- 图片：正常彩色显示
- 边框：2px 透明（默认）/ 2px 绿色(#4CAF50)（当前使用中）
- 圆角：12px
- 名称：正常黑色文字
- 状态标签：
  - 「使用中」：绿色背景圆角标签，位于卡片右上角
- 交互：点击可设为当前形象

**未拥有形象：**
- 图片：grayscale(100%) 灰度显示 + 透明度 0.6
- 叠加层：中央显示 🔒 锁图标（白色，带半透明黑色圆形背景）
- 边框：2px 虚线 #E0E0E0
- 名称：灰色(#9E9E9E)文字
- 交互：不可点击，hover 无效果

**卡片尺寸：**
- 宽度：自适应（网格均分）
- 图片容器：正方形，aspect-ratio 1:1
- 图片填充：object-fit: contain，内边距 8px
- 背景色：#F5F5F5

### 3.5 设为当前形象交互

1. 用户点击已拥有的非当前形象卡片
2. 卡片添加选中动效：scale(0.95) → scale(1)，0.2s
3. 弹出确认提示（底部 Toast）：「已将「小航·宇航员」设为当前形象」
4. 弹框关闭，首页AI助手形象切换为新形象
5. 原「使用中」标签消失，新卡片显示「使用中」标签

### 3.6 空状态

若用户没有任何形象（仅默认）：
- 展示默认形象卡片（已拥有且使用中）
- 底部提示文案：「抽取盲盒可获得更多形象哦~」+ 【去抽取】按钮

### 4.5 盲盒展示区

- 位置：弹框中央
- 盲盒图标尺寸：160×160px
- 默认状态：静态盲盒图片/emoji 🎁
- 背景：圆形浅色背景(#FFF3E0)，直径 200px

### 4.6 抽取按钮

- 文案：「抽取盲盒」
- 尺寸：宽度 200px，高度 48px
- 圆角：24px
- 默认状态：
  - 背景：线性渐变(135deg, #66BB6A, #43A047)
  - 文字：白色，16px，加粗
  - 阴影：0 4px 12px rgba(76,175,80,0.3)
- 禁用状态：
  - 背景：#E0E0E0
  - 文字：#9E9E9E
  - 无阴影
- 点击态：scale(0.97)，0.1s

### 4.7 抽取动画流程

**阶段1：点击抽取**
1. 用户点击【抽取盲盒】按钮
2. 按钮禁用，显示 Loading 状态
3. 盲盒开始抖动动画（见 4.8）

**阶段2：开盒动画**
1. 盲盒抖动 0.8s 后
2. 盲盒盖子打开（CSS transform rotateX）
3. 盒内发出金色光芒（radial-gradient 光效扩散）
4. 彩色纸屑/星星粒子从盒中喷出（CSS animation，8-12 个粒子）
5. 新形象从盒中缓缓升起（translateY + opacity）

**阶段3：结果展示**
1. 光芒渐弱，形象清晰展示在中央
2. 形象尺寸放大到 180×180px
3. 下方显示文案：「恭喜获得「小航·宇航员」！」
4. 文案颜色：金色渐变文字
5. 【收入收藏】按钮出现

**阶段4：收入收藏**
1. 用户点击【收入收藏】
2. 形象缩小并飞向左上角（飞向首页AI助手区域的方向暗示）
3. 弹框关闭，首页AI助手形象更新为新获得的形象
4. 首页显示 Toast：「「小航·宇航员」已加入收藏！」

### 4.8 动画详细参数

**盲盒抖动动画：**
```css
@keyframes boxShake {
  0%, 100% { transform: rotate(0deg) scale(1); }
  10% { transform: rotate(-8deg) scale(1.05); }
  20% { transform: rotate(8deg) scale(1.05); }
  30% { transform: rotate(-6deg) scale(1.08); }
  40% { transform: rotate(6deg) scale(1.08); }
  50% { transform: rotate(-4deg) scale(1.1); }
  60% { transform: rotate(4deg) scale(1.1); }
  70% { transform: rotate(-2deg) scale(1.12); }
  80% { transform: rotate(2deg) scale(1.12); }
  90% { transform: rotate(0deg) scale(1.15); }
}
/* duration: 0.8s, ease-in-out */
```

**光芒扩散动画：**
```css
@keyframes glowExpand {
  0% { transform: scale(0); opacity: 1; }
  100% { transform: scale(3); opacity: 0; }
}
/* duration: 0.6s, ease-out */
```

**形象升起动画：**
```css
@keyframes figureRise {
  0% { transform: translateY(40px) scale(0.5); opacity: 0; }
  60% { transform: translateY(-10px) scale(1.1); opacity: 1; }
  100% { transform: translateY(0) scale(1); opacity: 1; }
}
/* duration: 0.8s, cubic-bezier(0.34, 1.56, 0.64, 1) */
```

**粒子喷射动画：**
- 粒子数量：10 个
- 粒子形状：⭐ 星星 / ✨ 闪光（emoji 或 CSS 绘制）
- 颜色：金色(#FFD700)、粉色(#FF6B9D)、蓝色(#4FC3F7)
- 每个粒子随机方向喷射，抛物线运动
- duration: 0.8-1.2s，随机延迟

### 4.9 防重复机制

- 前端维护用户已拥有的形象 ID 列表
- 抽取时只从「未拥有形象池」中随机选择
- 若所有形象都已拥有：
  - 隐藏抽取按钮
  - 盲盒区显示：「🎉 你已经集齐了所有形象！」
  - 下方显示：「继续保持学习，未来会有更多形象上线哦~」

### 4.10 收藏进度条

- 位置：抽取按钮下方
- 文案：「我的收藏进度：{已拥有数} / {总数}」
- 进度条：
  - 背景：#E0E0E0，高度 8px，圆角 4px
  - 填充：线性渐变(90deg, #66BB6A, #43A047)
  - 宽度：按百分比动态计算

## 5. 状态与数据

### 5.1 数据结构（前端模拟）

```javascript
// 形象配置
const figures = [
  { id: 'base', name: '小航·基础版', image: '机机基础形象.png', default: true },
  { id: 'astronaut', name: '小航·宇航员', image: '宇航员.png' },
  { id: 'athlete', name: '小航·运动员', image: '运动员.png' }
];

// 用户数据（由后端提供）
const userData = {
  currentFigureId: 'base',        // 当前使用的形象ID
  ownedFigureIds: ['base'],       // 已拥有的形象ID列表
  drawCount: 3                    // 剩余抽奖次数
};
```

### 5.2 状态流转

```
首页默认状态
    ↓
点击【我的形象】→ 打开收藏弹框
    ↓
点击已拥有非当前形象 → 设为当前形象 → 弹框关闭 → 首页更新
    ↓
点击【抽取盲盒】→ 打开盲盒界面
    ↓
点击【抽取】→ 播放动画 → 展示结果 → 点击【收入收藏】
    ↓
更新用户数据（形象加入 ownedFigureIds，currentFigureId 更新）
    ↓
弹框关闭 → 首页AI助手形象更新
```

## 7. 异常处理

| 场景 | 处理方式 |
|------|----------|
| 图片加载失败 | 显示占位图标（机器人 emoji 🤖）+ 形象名称 |
