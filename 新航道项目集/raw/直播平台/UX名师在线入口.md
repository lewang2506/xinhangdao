# 名师在线入口 - UX交互文档

**产品：** 新航道学习机 - 名师在线
**更新日期：** 2026-05-18
**关联页面：** 学习机首页、即时答疑、预约指导

---

## 1. 需求背景

名师在线作为学习机"应用"Tab下的核心功能模块，包含"即时答疑"和"预约授课"两个子功能。用户在首页或应用Tab点击"名师在线"后，需要先进入入口页面选择具体服务类型，再进入对应的功能流程。

## 2. 页面定位

| 项目 | 说明 |
|------|------|
| **页面名称** | 名师在线入口 |
| **入口位置** | 学习机首页 → 应用Tab → 名师在线 |
| **页面作用** | 功能分流：引导用户选择即时答疑或预约授课 |
| **下游页面** | 即时答疑流程 / 预约指导流程 |

## 4. 设计规范

### 4.1 整体风格

| 项目 | 说明 |
|------|------|
| **背景** | 蓝紫渐变动态背景（#667eea → #764ba2 → #2dd4bf），带呼吸动画 |
| **卡片风格** | 毛玻璃效果（backdrop-filter: blur + 半透明边框） |
| **交互反馈** | hover 上浮 + 边框高亮，active 微缩 |

### 4.2 顶部导航栏

| 元素 | 说明 |
|------|------|
| **返回按钮** | 左侧，白色文字，点击返回上一页 |
| **页面标题** | 居中，"名师在线"，白色加粗 |
| **状态图标** | 右侧，信号/电量等系统图标 |

### 4.3 入口卡片

| 元素 | 即时答疑 | 预约授课 |
|------|----------|----------|
| **图标** | ⚡ 闪电 | 📅 日历 |
| **标题** | 即时答疑 | 预约授课 |
| **描述** | 快速响应，一对一视频连线老师实时解答。适合紧急问题、考前突击、概念理解。 | 提前规划学习时间，预约心仪老师系统讲解。适合知识体系梳理、专题突破、长期提升。 |
| **点击交互** | 进入即时答疑流程 | 进入预约指导流程 |

**卡片样式：**
- 背景：rgba(255,255,255,0.12) 半透明
- 边框：1px solid rgba(255,255,255,0.25)
- 圆角：20px
- 内边距：32px
- 图标容器：64×64px，圆角18px，半透明背景

## 5. 交互规则

| 操作 | 结果 |
|------|------|
| 点击【返回】 | 返回学习机首页/应用Tab |
| 点击【即时答疑】卡片 | 跳转即时答疑首页（demo-ai-答疑-ipad.html） |
| 点击【预约授课】卡片 | 跳转预约指导页面（demo-预约指导-ipad.html） |
| 卡片 hover | 上浮6px + 放大1.02倍 + 边框高亮 |
| 卡片 active | 微缩0.98倍 |

## 6. 横竖屏适配

| 场景 | 横屏 | 竖屏 |
|------|------|------|
| 卡片布局 | 左右两列 | 上下单列 |
| 卡片宽度 | 50% - gap | 100% |
| 内边距 | 40px | 30px |
